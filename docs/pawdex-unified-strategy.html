PawDex 통합 전략 v1 · 병원 + 사료 커머스 결합

우리 아이 기록을 보고 골라주는 사료 — 정기배송으로 편하게, 건강 신뢰로 묶다

메인 매출은 로얄캐닌 사료(추천 → 구매 → 정기배송). 병원 연계·문서 보관은 추천의 신뢰와 기록 이동성을 높이는 보조 인프라. 핵심 무기는 "가격"이 아니라 기록 기반 추천 + 정기배송 편의 + 건강 데이터 락인. 쇼루밍(추천만 받고 타사 구매)을 정기배송과 데이터로 방어한다.

포지셔닝 가치 루프 쇼루밍 방어 병원(보조) 단가 체크리스트 물류 체크리스트 법·규제 로드맵 핵심질문·KPI

1. 포지셔닝 — "최저가" 버린다

쿠팡·펫프렌즈 상대로 가격은 못 이긴다. 가격을 앞세우면 마진만 깎이고 지는 싸움. 차별화는 끝까지 "추천·편의·신뢰".

한 줄 메시지

이렇게 말한다

"우리 아이 기록을 보고 맞는 사료를 골라주고, 떨어질 때쯤 알아서 보내주는 — 건강을 아는 사료 정기배송."

이렇게 말하지 않는다
  • "최저가" / "가장 싸게"
  • "AI가 진단·처방"
  • "이 사료가 치료"
정체성 유지

헬스 신뢰가 자산

사료몰로 무게중심이 옮겨가도 "건강 기록 신뢰"가 추천의 근거. 광고처럼 보이면 추천이 죽는다.

2. 가치 루프 (해자의 본질)

단품 기능 나열이 아니라, 데이터가 돌면서 갈수록 강해지는 루프가 PawDex만의 무기.

1

기록

증상·진료·체중·복약·검사결과 + 프로필(종/나이/중성화/알러지)

2

추천

기록 기반 사료 후보(일반/기능/처방 분리) + 근거 + 급여·소진일 계산

3

구매·정기배송

첫 구매(쿠폰 넛지) → 소진일 맞춘 자동배송 전환

4

피드백

기호성·변상태·체중·알러지 반응 기록

5

개선·결합

다음 추천 정밀화 + 병원문서/응급카드/Plus 결합

핵심: 4·5번(피드백·데이터)이 쌓일수록 쿠팡이 못 따라하는 "우리 아이를 아는" 상태가 됨 = 진짜 락인.

3. 쇼루밍 방어 — "추천만 받고 타사 구매" 막기

같은 로얄캐닌(커머디티)이라 추천만으론 약하다. 쿠폰만으론 못 이긴다(마진 싸움 패배). 락인은 강도 순으로 설계.

락인 수단강도역할주의
쿠폰/할인약첫 구매·첫 정기배송 전환 넛지(1회성)상시 할인 X — 마진만 깎임, 따라하기 쉬움
적립금중앱 전용·Plus 전환 가능 적립 → 재방문 유도현금 환급 X (앱 안에서만)
정기배송(autoship)강소진일 자동관리 → 비교를 멈추게 함 (Chewy 해자)품절·가격변경 사전알림 필수
데이터 루프 + 건강결합최강피드백→추천개선, "정기배송=Plus 무료" 결합장기·복리 효과 (당장은 약함)
퍼널: 추천(신뢰) → 첫구매(쿠폰 넛지) → 정기배송 전환(락인) → 피드백(이탈방지) → 건강결합. 쿠폰은 "습관을 시작시키는 1회용 점화", 유지는 편의·데이터로.
가격은 "최저가" 말고 "합리적 + 알아서 챙겨줌". 정기배송 할인으로 "쿠팡과 비슷하거나 약간 저렴 + 자동" 포지션이면 충분.

4. 병원 연계 — 메인 아님, "신뢰·이동성" 보조 인프라

병원 EMR 대체 X. 보호자-병원 사이 문서·예약·기록이동만. 비용 적고 가치 큰 것부터.

계약 병원 (쓰기 권한)
  • 병원 웹툴: 보호자 연결(QR) → 검사결과·진단서 전송
  • 담당 수의사 예약 슬롯
  • 동의된 기록 열람
비계약 병원 (보호자 주도 읽기) ★싸고 강함
  • 24h 임시 링크 / QR / PDF 내보내기
  • 응급 패키지(최근기록+약+알러지+검사결과)
  • 열람 로그 + 즉시 철회
우선순위 조정: 계약병원 웹툴(B2B 영업·교육 부담 큼)보다 비계약 내보내기(영업 0, 클라이언트만)를 먼저. 병원 없어도 앱 쓸 이유 = 리텐션.

5. 💰 단가(Unit Economics) 체크리스트 — 빌드 전 필수

사료 커머스는 앱 기능이 아니라 유통·마진 사업. 아래가 안 풀리면 만들어도 적자.

건당 손익 (봉지 1개 기준)
  • 총판 공급가(원가) — 제품/용량별
  • 판매가 — 쿠팡 대비 ±몇 %로 둘지
  • = 매출총이익 = 판매가 − 공급가
  • − 결제수수료 (Toss 약 2~3%)
  • − 배송비 (누가 부담? 고객/우리/무료기준)
  • − 포장·운영·CS 분담
  • − 쿠폰/적립 비용
  • = 건당 실마진 (양수인가?)
사업 단위
  • 월 손익분기 주문 수
  • 정기배송 할인율 → 마진 영향 시뮬
  • CAC(고객획득비, 광고/쿠폰 포함)
  • LTV = 정기배송 유지 개월 × 건당 마진
  • LTV > CAC 배수 (목표 3배+)
  • 정기배송 전환율 / 이탈율(churn) 가정
  • 객단가 + 재구매 주기
경고: 단일 브랜드(로얄캐닌)만 팔면 "맞춤 추천"이 "어떤 로얄캐닌?"이 됨 = 로얄캐닌 자사 도구와 차별 약함 + "팔 것만 추천" 신뢰 문제. 멀티 브랜드 확보 여부를 마진과 함께 결정.

6. 🚚 물류·운영 체크리스트

풀필먼트
  • 주체: 총판 드롭십 / 직재고 / 3PL 중 무엇
  • 재고·품절 동기화 (총판 재고 API 있나?)
  • 배송 리드타임 / 택배사 / 송장 흐름
  • 정기배송 출고 스케줄 자동화
  • 가격·품절 변경 시 고객 사전알림
운영·CS·정산
  • 반품/교환/환불 흐름 + 비용 부담 주체
  • CS 채널·응대 (배송·변심·파손)
  • 정산: 총판↔PawDex↔(판매자) 주기·수수료
  • 주문 상태 추적 (결제/출고/배송/완료)
  • 운영 인력 — 누가 이 운영을 감당?
가장 쉬운 시작: 총판 드롭십(우리가 재고 0) + 정기배송부터. 재고·창고·3PL은 검증 후.

7. ⚖️ 법·규제 체크리스트

  • 통신판매업 신고
  • 전자상거래법: 사업자정보·청약철회·교환반품 고지 의무
  • 사료관리법: 사료 표시사항 (수입/제조사 등)
  • 결제: Toss 단건결제 심사 완료 (현재 진행 중) — 일반구매 전제 / 정기배송은 빌링으로 선행 가능
  • 마켓플레이스화 시: 통신판매중개 + 에스크로/정산
  • 병원 연계: 수의사법(원격진료 X, 진단/처방은 수의사) + 개인정보보호법(민감정보 동의·암호화·열람로그·철회)
  • AI 추천: 치료·진단 단정 금지, "수의사 상담 권장" 표기

8. 통합 로드맵 (지금 되는 것부터)

단건결제 심사에 막히지 않게, 지금 되는 정기배송(빌링)과 영업 0짜리 내보내기를 앞으로.

0순위

단가·물류·총판 조건 확정

위 체크리스트로 "건당 남는가"부터. 여기서 사업 성립 여부 결정. 코드보다 먼저.

1순위

로얄캐닌 카탈로그 + 상품/상세

상품·옵션·가격·재고·생애주기/질환 태그. 총판 1곳 전용 판매자 관리부터 작게.

2순위 · 지금 됨

정기배송(빌링) + 소진일 계산

이미 있는 Toss 빌링 확장. 단건 승인 없이 매출 검증 가능. 쇼루밍 방어 핵심.

3순위

AI 사료 추천 엔진

프로필·기록·AI 분석 → 카탈로그 태그 매칭. 추천은 카탈로그 안에서만. 근거+상담표시.

4순위

일반구매(단건) + 장바구니

Toss 단건 승인 후 바로구매·주문내역. 추천 영역과 일반 쇼핑 분리.

5순위 · 영업 0

병원 내보내기/응급 공유 카드

24h 링크·QR·PDF. 계약 병원 없어도 가치 + 리텐션. 클라이언트 중심이라 가벼움.

6순위

병원찾기 하단 액션 패널 + 제휴 배지

지도 2/3 + 예약/전화/길찾기/기록공유/문서함. 제휴 병원 기능형 홍보.

7순위

A 병원 1곳 문서전송 MVP → 예약/응급콜

계약병원 깊은 연동은 1곳 검증 후. 운영 부담 커서 가장 뒤.

메인: 기록 기반 추천 + 정기배송 락인: autoship + 데이터 + 건강결합 리텐션: 응급 내보내기(영업0) 확장: 계약병원 문서·예약

9. 성패를 가를 핵심 질문 + KPI

먼저 답해야 할 질문
  1. 풀필먼트 주체 + 건당 실마진은?
  2. 단일 브랜드로 "추천 신뢰" 서나? (멀티 필요?)
  3. 구매자 = 기존 헬스 유저 전환 vs 신규 고객?
  4. 헬스 정체성 흔들림 없이 사료몰 결합 가능?
추적할 KPI
  • 추천 → 첫구매 전환율
  • 첫구매 → 정기배송 전환율 (가장 중요)
  • 정기배송 유지(churn) / LTV
  • 재구매 주기·객단가
  • 응급 내보내기/문서함 사용률(리텐션 지표)
결론: 사료 방향은 매출이 더 빠르지만 사업 난이도(유통·마진·운영)는 더 높다. 0순위(단가·물류) 검증 후, "지금 되는 정기배송 + 영업0 내보내기"로 가볍게 시작 → 데이터·매출 보고 병원·일반구매 확장.
